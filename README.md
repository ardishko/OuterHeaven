## ❓ Why the move

As this is a personal project and cryptographic keys are stored in this project,
Github's own AI scraping and policy about not preventing others from doing it
raises security concerns for me as an individual. Codeberg actively fights
scraping with tools like Anubis. While it is not perfect (for example, some
crawlers have learned to solve the Anubis challenges), the fact that there is an
active effort to prevent it is enough.

Full disclosure: I, as an individual am not concerned about my code being used
but rather my encrypted data like passwords, tokens and IPs being referenced and
being mixed into AI datasets to be easily searchable in the future. While I'm
aware that this has most likely already happened given how late my move was,
this is simply an effort to keep more crawlers from scraping data that could be
decrypted in the future. It's not about having perfect security, it's about
minimizing the attack surface. (yes I know that sounds very AI-like but that's
genuinely how I talk)

## 🙋 What does this mean for my other projects

They will be judged on a case by case basis. Github is huge and gives you way
more exposure than you could get elsewhere for finding contributors, so I am
trying to benefit from the best of both worlds. Projects with cryptography
involved (basically anything vulnerable to the "collect now, harvest later"
approach) go to Codeberg, everything else stays on Github.
